# API Reference

This directory contains the API documentation for the Photonic Neuromorphic Computing library.

## Sections
- **C API**: Details of the `pho_*` functions exposed in `interface/c_api.h`.
- **Python Binding**: Usage of the `PhotonicLib` Python wrapper.
- **Rust Binding**: Usage of the `Photonic` safe Rust wrapper.
- **PhoLang Specification**: Syntax, grammar, and semantics of the PhoLang DSL.
